# Pillars website

Front-end files for the Pillars homepage (thepillarsapp.com).

- `index.html` — standalone reference build of the homepage
- `styles.css`, `app.js` — stylesheet and script loaded by the Webflow page
- `assets/` — images, video clips and fonts used by the page (see `ASSETS.md`)

The Webflow page loads these files through jsDelivr, pinned to a tag.
